# 온라인팀 거래처 매출 대시보드

회사 ERP **일일판매실적**과 온라인팀 **월 마감내역(거래처별 공제·물류비)** 엑셀로 만드는 대시보드입니다.

- 거래처별 매출액 카드 (공제·물류비, 담당자 필터, 검색·정렬)
- 선택한 거래처의 기간별 매출 추이 (전년 동기 비교)
- SKU 판매 현황 (전년 수량, 최다 판매단가·부가세 포함) → SKU를 누르면 상세 창
- 구역마다 기간을 따로 설정 (7일 / 30일 / 당월 / 올해 / 전체)

## 데이터 갱신 방법

1. 저장소에서 폴더를 엽니다.
   - ERP 일일판매실적 → `input/erp`
   - 월 마감내역 → `input/costs`
2. **Add file → Upload files**로 엑셀을 끌어다 놓고 **Commit changes**를 누릅니다.
3. 2~3분 뒤 **Actions** 탭의 "데이터 갱신·배포"가 초록색이 되면 대시보드에 반영됩니다.

### 파일 규칙

- **ERP 파일**: ERP에서 받은 이름 그대로 올려도 됩니다. 기간이 겹치면 **더 최근에 받은 파일**이 그 기간을 통째로 대신합니다.
  (파일 이름 속 다운로드 시각 `Excel_20261123180857` 기준, 없으면 올린 시각 기준)
  그래서 같은 기간을 다시 받아 올리면 수정된 실적으로 바뀌고, 중복으로 세지 않습니다.
- **마감내역 파일**: 첫 시트의 "이번 달" 열을 씁니다. 같은 달 파일이 여러 개면 더 최근에 올린 파일을 씁니다.
- 파일을 지우면 그 기간 데이터도 대시보드에서 빠집니다.

## 기준

- 매출액·공제·물류비는 VAT 제외, **최다 판매단가만 부가세 포함**(ERP 판매단가와 같은 기준)입니다.
- 거래처는 ERP의 `거래처` 열 기준입니다. (2025년 파일의 '쿠팡(대표)'는 쿠팡 직매입·쿠팡으로 나뉩니다.)
- 담당자·채널은 그 거래처의 가장 최근 실적 기준입니다.
- 전년 비교는 이번 기간과 전년 같은 기간 모두 데이터가 빠진 달이 없을 때만 표시합니다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `input/` | 원본 엑셀 (여기에만 올리면 됨) |
| `data/` | 자동으로 만들어지는 CSV (직접 고치지 않기) |
| `scripts/` | 엑셀 → CSV 변환 스크립트 |
| `assets/`, `index.html` | 대시보드 화면 |

로컬에서 데이터만 다시 만들려면: `pip install pandas openpyxl` 후 `python scripts/build_all.py`
